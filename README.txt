# WhatsApp Lead Form

This is a simple Name + Company Name form configured for WhatsApp number +91 9787605132.

Flow:
QR Code → Form → Submit → WhatsApp

Important:
The QR code cannot reliably point to a local HTML file. First deploy `index.html` to a public HTTPS URL, such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages. Then create a QR code containing that public URL.

The form itself requires no backend.
